# Async JavaScript & Fetch – User Directory

## About
This project is a simple User Directory web application that fetches user information from a free public API using JavaScript.

It demonstrates asynchronous JavaScript concepts such as Promises, async/await, fetch(), and error handling.

## Features
- Fetch user data from a public API.
- Display user name, email, and company.
- Show loading state while fetching data.
- Handle API errors using try...catch.
- Display an empty state when no users are found.
- Show a success message after fetching data.

## Technologies Used
- HTML
- CSS
- JavaScript
- JSONPlaceholder API

## API Used
https://jsonplaceholder.typicode.com/users

## How to Run
1. Download or clone the repository.
2. Open the async-fetch folder in VS Code.
3. Open index.html using Live Server.
4. Click the Load Users button.
5. View the user information.
