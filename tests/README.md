
# JavaScript 15 Exercises

## About
This repository contains 15 basic JavaScript exercises created to practise JavaScript fundamentals.

## Topics Covered
1. Variables
2. Functions
3. Arrow Functions
4. Array Basics
5. Map()
6. Filter()
7. Reduce()
8. Objects
9. Object Destructuring
10. Array Destructuring
11. Rest Operator
12. Spread Operator
13. Array Methods
14. Export Module
15. Import Module

## How to Run

Run an individual exercise:

node exercises/01-variables.js

Run automated tests:

npm.cmd test

- JavaScript
